Janiyah's Abode
An interactive, draggable tin-box personal portfolio.\

## Introduction

Welcome to my personal website! This project is a custom frontend portfolio designed to showcase my coding experience and personality. The site features a unique, interactive tin-can interface where visitors can explore my space by dragging, dropping, and clicking various trinkets (like my earbuds, matcha, and keys) in and out of the box. It was built entirely from scratch utilizing HTML, CSS, and vanilla JavaScript.


## Installation Instructions for Users

No installation is required! Because this is a static frontend website, you can interact with the live project directly in your web browser.

View the live site here: https://janiyahlanell.github.io


## Contributor Expectations

As this is my personal portfolio, I am not currently accepting pull requests for new features or design changes. However, if you spot a bug (such as a broken file path or a styling issue on a specific browser), feel free to open an Issue on the repository, and I will gladly take a look!

## Known Issues
Mobile Responsiveness: The drag-and-drop JavaScript functions are currently optimized for desktop mouse events. Touchscreen dragging on mobile devices may occasionally be rigid or unresponsive depending on the browser.

(Feel free to add any other quirks or bugs you notice here!)
